Wanna Know If You Have An INDEXED version?
do you have these files?
index.json
pynch_db

if you do no need to run indexer.py unless you experience errors
if you dont then run indexer.py to get an indexed version

Why Indexing not run straight away?

because 3 gigabytes of pure raw English dictionary data would fry any computer to load so python has to crash 
index.json just tells the tool where everything is like a book index
so it doesnt have to filter through the dictionary file everytime you are looking for 1 word

How To Index?
just run  

```bash
git clone [https://github.com/DAPOWER99/Pynch.git](https://github.com/DAPOWER99/Pynch.git)
cd Pynch
python index.py
```
